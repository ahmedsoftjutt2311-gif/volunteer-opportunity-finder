# Lab Report — Volunteer Opportunity Finder App

## Objective
Develop a polished Flutter application using Dart and Material 3.

## Features
- Material 3 interface
- Navigation
- Icons
- Interactive forms/dialogs
- Search/filtering where applicable
- Animated entrance transitions
- Local state management

## Tools
Flutter SDK, Dart, VS Code or Android Studio.

## Testing
Run `flutter pub get`, `flutter analyze`, `flutter test`, and `flutter run`.
Test every button, form, navigation destination, dialog, and state-changing action.

## Conclusion
The project demonstrates practical Flutter UI design, interaction handling, navigation, forms, animations, and local state management.
